This is a living document on the ongoing development of the LORA training pipeline for the different video models that we use. The obejctive is to create loras for:

- Character consistency
- Character detailing
- Hyper realistic output
- Cloth simulation
- Hair Simulation
- Props, accesories

It's based on the following open source models:

- WAN 2.1
- WAN 2.2 VACE
- WAN 2.2 Fun Control
- WAN 2.2 Animate
- WAN SCAIL
- LTX 2.3
