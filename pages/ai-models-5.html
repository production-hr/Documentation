5. ComfyUI Folder Guide

ComfyUI scans specific subdirectories for each file type — wrong folder means the model won't appear in dropdowns.

ComfyUI scans specific subdirectories under models/ for each file type. Wrong folder = model won't appear in dropdowns. The key split for modern models is: the diffusion model, the text encoder(s), and the VAE are all separate files in separate folders.

Folder Reference

Folder Path What Goes Here Why / Which Node Loads It Filename Examples
models/checkpoints/ Full all-in-one model files SDXL checkpoints, fine-tuned merged models. Contains UNet + CLIP + VAE baked together in one file. Loaded with "Load Checkpoint" node. dreamshaper-xl.safetensors
sdxl_base_1.0.safetensors
models/diffusion_models/
(also: models/unet/)		 Standalone diffusion model (DiT/UNet only) Flux.1, Flux.2, SD3, Z-Image, Qwen-Image main model files — no encoders or VAE included. Loaded with "Load Diffusion Model" node. Both folder names are scanned; diffusion_models/ is the current standard. flux1-dev.safetensors
flux2-dev-Q4_K_M.gguf
z-image-turbo.safetensors
qwen-image-2512-fp8.safetensors
models/clip/
(also: models/text_encoders/)		 Text encoder models CLIP, T5-XXL, Mistral-3, Qwen3-4B, Qwen-VL — whichever text encoder the model uses. Flux.1 needs both CLIP-L and T5-XXL. Flux.2 needs Mistral-3. Loaded with "DualCLIPLoader" or "CLIPLoader". Both folder names scanned. t5xxl_fp8_e4m3fn.safetensors
clip_l.safetensors
mistral_3_small_flux2_fp8.safetensors
qwen2.5-vl-7b-instruct-q8.gguf
models/vae/ Variational Autoencoder Always a separate file for modern models. Every model family needs its own VAE — they are NOT interchangeable. Loaded with "Load VAE" node. ae.safetensors (Flux.1)
flux2-vae.safetensors (Flux.2)
vae-ft-mse-840000-ema-pruned.safetensors (SDXL)
models/loras/ LoRA adapter files Style/character/concept fine-tune adapters. Must match the base model architecture. Apply with "Load LoRA" node — does not replace the base model, stacks on top of it. flux-realism-lora.safetensors
sdxl-lightning-4step-lora.safetensors
models/controlnet/ ControlNet models Condition generation on depth, edges, pose, etc. Must match base model (SDXL ControlNet ≠ Flux ControlNet). Loaded with "Load ControlNet Model" node. controlnet-depth-sdxl.safetensors
xlabs-flux-depth-controlnet.safetensors
models/upscale_models/ Image upscaling models Post-processing upscalers like RealESRGAN, ESRGAN, 4xUltrasharp. Used after image generation to increase resolution. Loaded with "Load Upscale Model" node. RealESRGAN_x4plus.pth
4x-UltraSharp.pth
models/clip_vision/ CLIP Vision encoder Image understanding encoder used by IP-Adapter, image-to-image conditioning, reference workflows. Different from text CLIP. clip-vit-large-patch14.safetensors
IP-Adapter-Plus-SDXL.safetensors
models/ipadapter/ IP-Adapter models Image Prompt Adapter — lets you use a reference image as a style/content guide alongside text prompts. ip-adapter-plus_sdxl_vit-h.safetensors
ip-adapter-flux.safetensors
models/embeddings/ Textual Inversion embeddings Very small files that teach the model a new token/concept. Mainly used with SD1.5/SDXL. Reference in prompt as <embedding_name>. bad-hands-5.pt
negative-hand-neg.pt
models/unet/ and models/diffusion_models/ are both scanned for the same file type — either works. Current convention is diffusion_models/. Similarly, models/clip/ and models/text_encoders/ both work for text encoders. GGUF diffusion models (.gguf) go in models/unet/ and require the ComfyUI-GGUF custom node. Without it, GGUF files will not load.

Per-Model File Placement

Model Diffusion Model → Text Encoder(s) → VAE → ComfyUI Node(s)
SDXL (checkpoint) checkpoints/ (baked in) (baked in) Load Checkpoint
Flux.1 dev/schnell diffusion_models/ clip/ (CLIP-L + T5-XXL) vae/ Load Diffusion Model + DualCLIPLoader + Load VAE
Flux.2 dev/klein diffusion_models/ text_encoders/ (Mistral-3) vae/ Load Diffusion Model + CLIPLoader + Load VAE
Z-Image Turbo diffusion_models/ text_encoders/ (Qwen3-4B) vae/ Load Diffusion Model + CLIPLoader + Load VAE
Qwen-Image-2512 diffusion_models/ text_encoders/ (Qwen-VL) vae/ Load Diffusion Model + CLIPLoader + Load VAE
Flux.1 Kontext [dev] diffusion_models/ clip/ (CLIP-L + T5-XXL) vae/ Load Diffusion Model + DualCLIPLoader + Load VAE
Any GGUF model unet/ ← use this for .gguf clip/ (GGUF or safetensors) vae/ (.safetensors) Unet Loader (GGUF) — requires ComfyUI-GGUF custom node
SDXL checkpoints contain all three components in one file, so they use the simpler "Load Checkpoint" node. All modern DiT models (Flux, Qwen, Z-Image) split components into separate files requiring separate loaders.
