ComfyUI: Installation & Setup

Step-by-step installation on Windows with CUDA, the essential Manager extension, every useful launch flag, and how to keep ComfyUI up to date.

This guide uses a Python virtual environment install on Windows with CUDA — the recommended local method. A venv keeps ComfyUI's dependencies isolated from your system Python and makes updates straightforward. If you're on Linux or Mac the clone-and-venv steps are identical; only the activation command differs.

Prerequisites

Confirm these are in place before running a single command. Missing any one of them is the most common cause of a failed install.

Requirement Minimum Version Notes
Python 3.10 – 3.12 3.11 is the most tested. Avoid 3.13+ — some dependencies lag. Download from python.org; check Add to PATH during install.
Git Any recent version Required to clone ComfyUI and install extensions. Download from git-scm.com.
NVIDIA GPU 8 GB VRAM minimum 6 GB is possible with quantised models (GGUF Q4). 16 GB+ recommended for Flux.1. AMD via ROCm is supported but less tested.
CUDA Toolkit Matching your GPU driver Installed automatically with PyTorch. Check your driver's max supported CUDA version with nvidia-smi.
Disk space 20–60 GB free ComfyUI itself is small. Models are large: SDXL ~6 GB, Flux.1 dev ~24 GB (BF16), ~9 GB (Q4 GGUF).

Install Steps

Run the following in PowerShell or Windows Terminal. Each block is a logical step — complete them in order.

Step 1 — Clone ComfyUI

git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

Step 2 — Create and activate a virtual environment

python -m venv venv
.\venv\Scripts\activate
Note
Your prompt will show (venv) when the environment is active. You must activate it every time you open a new terminal before launching ComfyUI.

Step 3 — Check your CUDA version

nvidia-smi

Look for CUDA Version: XX.X in the top-right of the output. This is the maximum CUDA version your driver supports.

Step 4 — Install PyTorch

Get the exact command for your CUDA version at pytorch.org/get-started/locally. 

# Example for CUDA 12.1:
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# Example for CUDA 11.8:
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Step 5 — Install ComfyUI requirements

pip install -r requirements.txt

Step 6 — Optional: SageAttention + Triton

pip install sageattention
pip install -U triton-windows
Note
SageAttention provides faster attention computation on modern GPUs. triton-windows is a Windows-compatible build of Triton — required by SageAttention on Windows. If the install fails, ComfyUI still works without them.

Step 7 — First launch

python main.py

ComfyUI will print a local URL (default: http://127.0.0.1:8188). Open it in your browser. On first run it may download a small default checkpoint.

ComfyUI Manager

ComfyUI Manager is the essential extension for installing custom nodes, updating ComfyUI, and downloading models. Install it once, then use it for everything else. 

cd custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
cd ..
.\venv\Scripts\activate
pip install -r custom_nodes\ComfyUI-Manager\requirements.txt
python main.py

After relaunch, a Manager button appears in the ComfyUI menu bar. Use it to install missing nodes (when a workflow requires them), update all nodes, and browse and install models from CivitAI and Hugging Face.

Useful Launch Flags

Pass these flags to python main.py to change ComfyUI's behaviour at startup. Multiple flags can be combined.

Flag Example What It Does
--port python main.py --port 8189 Change the port ComfyUI listens on. Useful if 8188 is taken.
--listen python main.py --listen Accept connections from other devices on your network (not just localhost). Required for tablet/phone access.
--lowvram python main.py --lowvram Aggressive VRAM offloading to RAM. Slower but lets you run large models on limited VRAM (6–8 GB). Prefer --medvram first.
--medvram python main.py --medvram Moderate VRAM offloading. Good balance for 8–10 GB GPUs running SDXL. Less speed penalty than --lowvram.
--fp8_e4m3fn python main.py --fp8_e4m3fn Load model weights in FP8 format. Halves VRAM usage vs BF16 with minor quality loss. Requires Ampere GPU (RTX 30xx+).
--fp16-vae python main.py --fp16-vae Run VAE in FP16. Saves VRAM during decode. Can cause NaN errors on some models — use the fp16-fix VAE instead if problems occur.
--disable-xformers python main.py --disable-xformers Disable xformers attention. Try this if you get crashes or artefacts with xformers installed.
--preview-method latent2rgb python main.py --preview-method latent2rgb Show fast latent previews during generation without decoding through VAE. Recommended — much faster feedback with minimal overhead.
--fast python main.py --fast Enable experimental speed optimisations. May cause minor quality changes. Worth testing on your hardware.
Tip
Create a launch.bat file in your ComfyUI folder with your preferred flags so you don't have to type them every time: 
echo .\venv\Scripts\activate && python main.py --preview-method latent2rgb --fp8_e4m3fn > launch.bat

Updating ComfyUI

Run from the ComfyUI folder with venv active: 

git pull
.\venv\Scripts\activate
pip install -r requirements.txt

Or use the Manager button → Update ComfyUI. Custom nodes can be updated individually via Manager → Update All. After major updates, re-run pip install -r requirements.txt to catch any new dependencies.

With ComfyUI running, continue to the Interface Walkthrough to learn how to navigate the canvas and understand the node graph.
