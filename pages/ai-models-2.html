2. Variant & Suffix Labels

Suffix labels decode a model's training strategy, speed tier, commercial license, and intended use.

These suffixes describe training strategy, speed characteristics, and commercial usage rights.

Label What It Means Practical Implication Example Models
[dev] Open weights, non-commercial Use for research, fine-tuning, LoRA training. Outputs not for commercial use without purchasing a commercial license from the developer. Flux.1 [dev], Flux.2 [dev], Flux.1 Kontext [dev]
[schnell] Speed-distilled — German for "fast" Fewer steps, Apache 2.0 free commercial use. Best for rapid iteration, demos, real-time. Slight quality trade-off. Flux.1 [schnell]
[klein] Smaller/efficient — German for "small" Consumer-GPU-friendly version. Apache 2.0. Same architecture as dev sibling, lower VRAM requirement. Flux.2 [klein]
[pro] Closed-source, API only Top quality tier. No local weights. Paid-per-image API. Best for production where quality outweighs cost. Flux.1 [pro], Flux 1.1 Pro, Flux.1 Kontext [pro/max]
Ultra / Raw Resolution / style modes (Pro only) Ultra = up to 4MP without speed penalty. Raw = hyper-realistic candid photography with authentic imperfections. Flux 1.1 Pro Ultra, Pro Raw
Turbo Aggressive step distillation 4–8 inference steps instead of 20–50. Near-instant generation. Some quality softening on fine detail. Z-Image Turbo, SDXL-Turbo
Lightning Even faster distillation (community) 1–4 steps. Community-distilled versions of existing models. More quality loss than Turbo. SDXL Lightning, Qwen-Image-Lightning
Kontext In-context image editing Takes existing image + text prompt, edits coherently. Different from pure T2I. Released May 2025. Flux.1 Kontext [dev/pro/max]
Edit / Fill Targeted image editing variant Trained for object replacement, inpainting, style transfer. Needs edit-specific workflow nodes. Qwen-Image-Edit-2511, Flux.1 Fill
LoRA Lightweight fine-tune adapter Small file (10–300 MB) stacked on top of a base model. Changes style, adds characters/concepts. flux-realism-lora.safetensors
Checkpoint Full fine-tuned model Complete baked weights with style/subject merged in. Larger (~5–25 GB). Loaded as a checkpoint. dreamshaper-xl.safetensors, JibMix-QI
