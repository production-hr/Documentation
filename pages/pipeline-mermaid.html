AI Character Pipeline — Mermaid

The full character pipeline rendered by Mermaid.js — the entire diagram is defined in ~40 lines of readable text syntax.

Mermaid compiles a plain-text description into an SVG at runtime. The source is human-readable, version-controllable, and easy to edit: adding a node means writing one line, not repositioning a dozen coordinates. The cost is a CDN dependency and some loss of layout control — Mermaid's auto-router decides connector paths and group positions.

Tradeoffs

Mermaid is the most maintainable option for a diagram that will evolve. The syntax is readable without tooling, diffs cleanly in git, and the renderer handles layout automatically. The downsides: you cannot precisely control connector routing, the CDN script adds a network request, and complex subgraph layouts sometimes produce unexpected results that require workarounds.

Dependency note: This page loads Mermaid from cdn.jsdelivr.net. If that CDN is unavailable the diagram will not render. For a production deployment, bundle mermaid.min.js locally alongside site.js.
