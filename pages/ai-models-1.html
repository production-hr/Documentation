1. Model Landscape

Core open-source image generation models in active use as of early 2026, with architecture, VRAM requirements, and typical filenames.

Core open-source image generation models in active use as of March 2026. API-only models included for comparison.

SDXL 1.0

Legacy open-source standard. Native 1024px with a massive fine-tune ecosystem. Requires CFG and negative prompts — being replaced by DiT models but still widely used.

Parameters~3.5B
ArchitectureUNet + CLIP
PrecisionBF16 / FP16
VRAM~6–8 GB
LicenseCreativeML Open RAIL+M — non-commercial by default
Filenamesdreamshaper-xl.safetensors · sdxl_base_1.0.safetensors

Flux.1 [dev]

Open weights, non-commercial. Guidance-distilled from Flux.1 [pro]. Best detail of the open Flux.1 models and the standard base for LoRA training. Uses CLIP-L + T5-XXL text encoders.

Parameters12B
ArchitectureDiT / Flow Matching
PrecisionBF16 / FP8
VRAM~16 GB (BF16) · ~8–9 GB (Q4 GGUF)
Steps20–50
LicenseFLUX.1 [dev] Non-Commercial License
Filenamesflux1-dev.safetensors · flux1-dev-Q4_K_M.gguf

Flux.1 [schnell]

Apache 2.0 — full commercial use. Adversarial-distilled for 1–4 steps only. Best for rapid iteration and drafts. Slight quality drop vs dev; same T5+CLIP encoders.

Parameters12B
ArchitectureDiT / Flow Matching
PrecisionBF16 / FP8
VRAM~16 GB (BF16) · ~8–9 GB (Q4 GGUF)
Steps1–4
LicenseApache 2.0
Filenamesflux1-schnell.safetensors · flux1-schnell-Q4_K_M.gguf

Flux 1.1 Pro (+ Ultra / Raw)

Closed source, API only via BFL, fal.ai, and Replicate. Best Flux.1-generation quality. Ultra reaches up to 4MP; Raw produces hyper-realistic candid photography. ~4.5s per generation.

Parameters12B+
ArchitectureDiT / Flow Matching
PrecisionCloud only — no local weights
VRAMAPI only
LicensePaid API
Accessbfl.ml · fal.ai · Replicate

Flux.1 Kontext [dev / pro / max]

Released May 2025. In-context image editing — takes an image plus a text prompt and edits coherently. Dev = open weights non-commercial. Pro/Max = API only. Adobe Photoshop beta integration.

Parameters12B
ArchitectureDiT / Flow Matching
PrecisionBF16 / FP8 (dev)
VRAM~16 GB (dev BF16)
LicenseDev: non-commercial · Pro/Max: paid API
Filenamesflux1-kontext-dev.safetensors

Flux.2 [dev]

Released Nov 2025. Non-commercial open weights. Mistral-3 24B LLM replaces T5 as the text encoder — massive prompt comprehension jump. Supports 32K-token prompts. Best open image model for complex scenes.

Parameters~32B
ArchitectureDiT + Mistral-3 24B encoder
PrecisionBF16 / FP8
VRAM~32–40 GB (BF16) · ~16 GB (Q4 GGUF)
LicenseNon-commercial open weights
Filenamesflux2-dev.safetensors · flux2-dev-Q4_K_M.gguf

Flux.2 [klein]

Apache 2.0 — fully free. "Klein" = small in German. Consumer GPU-friendly sibling of Flux.2 Dev with the same Mistral-3 LLM encoder advantage at lower VRAM cost.

ParametersSmaller than dev
ArchitectureDiT + Mistral-3 encoder
PrecisionBF16 / GGUF
VRAM~8–12 GB (Q4 GGUF)
LicenseApache 2.0
Filenamesflux2-klein.gguf · flux2-klein-Q4_K_M.gguf

Z-Image Turbo

Alibaba Tongyi Lab. Apache 2.0. Nov 2025. Photorealistic in under 3 seconds. Uses Qwen3-4B as an LLM text encoder. Best-in-class speed/quality ratio on consumer GPUs for its parameter count.

Parameters~6B
ArchitectureS3-DiT (single-stream)
PrecisionBF16 / FP8 / GGUF
VRAM~16 GB (BF16) · ~8 GB (Q4)
LicenseApache 2.0
Filenamesz-image-turbo.safetensors · z-image-turbo-fp8.safetensors

Qwen-Image-2512

Alibaba. Dec 2025 (2512 = year 25, month 12). Best-in-class bilingual text rendering. Exceptional prompt adherence — can be too literal; precise prompts produce exceptional results. Uses Qwen-VL vision-language model as the text encoder.

Parameters~20B
ArchitectureDiT + Qwen-VL encoder
PrecisionBF16 / FP8 / GGUF
VRAM~40 GB (BF16) · ~21 GB (Q8 GGUF)
LicenseApache 2.0
Filenamesqwen-image-2512-bf16.safetensors · qwen-image-2512-Q8.gguf
Flux.1 Kontext added May 2025. Flux.2, Z-Image Turbo, and Qwen-Image-2512 all released Nov–Dec 2025. Qwen-Image-2512 ranked #1 open-source on AI Arena blind testing (Dec 2025).
