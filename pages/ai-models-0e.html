0e. The Empty Latent Image Node

What the Empty Latent Image node actually creates, why it exists, and how Width × Height settings translate into the tensor the diffusion model works with.

Every txt2img workflow in ComfyUI contains an Empty Latent Image node. It is often overlooked because it feels like a trivial "set the canvas size" step — but understanding what it actually creates explains why the diffusion pipeline is structured the way it is.

What the node does: it creates a blank tensor of zeros in latent space — not a pixel canvas. This tensor is the starting point the KSampler will immediately fill with random Gaussian noise (seeded by your seed value) before denoising begins. Without it, the KSampler has nothing to work with.

Why latent space, not pixels? The diffusion model never sees or generates pixels. It works entirely inside the compressed latent space produced by the VAE encoder. At the end of the pipeline the VAE decoder converts the final denoised latent back into a pixel image. The Empty Latent Image node creates the correctly-shaped container for this latent-space process.

Node Settings

Setting What It Controls Detail
Width Output image width in pixels The node divides by 8 internally (VAE compression factor) to compute latent width. 1024 px → 128 latent units. Must be a multiple of 64 (SDXL) or 16 (DiT models).
Height Output image height in pixels Same 8× compression applies. Non-matching multiples cause artefacts or ComfyUI rounding errors.
Batch Size Number of images generated in one pass Batch 4 = 4 independent latents denoised in parallel. Multiplies VRAM usage roughly linearly. Each image in the batch uses a seed offset (+0, +1, +2…).

Latent Tensor Shape

Model Family Channels Latent Shape (1024×1024 example)
SDXL / SD1.5 4-channel [batch, 4, 128, 128]
Flux.1, Flux.2, Z-Image, Qwen-Image 16-channel [batch, 16, 128, 128] — encodes richer information per spatial unit, contributing to better fine detail and colour accuracy

What Happens After Creation

  1. The KSampler receives the empty latent and immediately populates it with random Gaussian noise using the seed value. The "empty" tensor is essentially discarded — the seed-noise is the true starting point.
  2. The diffusion model denoises this noise for N steps, guided by the text conditioning from the text encoder.
  3. The final clean latent exits the KSampler and goes to VAE Decode → pixel image.
In img2img workflows the Empty Latent Image node is not used — the input image is VAE-encoded into a real latent, partially noised, and fed directly to the KSampler. The Empty Latent Image node is exclusively a txt2img starting point. The Width and Height fields are the only place in a standard txt2img workflow where you set output resolution — they must respect the model's resolution constraints (see 0c: Resolution Constraints).
