Style Guide

Every typographic element, callout type, and structural pattern available in the documentation system, in one place. Use this as a copy-paste reference.

The first paragraph of any doc can use a drop cap by adding the class dropcap to it. The opening letter pulls in a heavier weight from the variable font and tints in the accent color. It's a small editorial flourish that signals the start of substantive content.

Body text uses a variable serif (Fraunces) optimized for long-form reading. Inline formatting includes bold for emphasis, italics for titles or stress, links with accent underline, and inline code for technical tokens.

Headings and hierarchy

The page uses one h1.doc-title for the document title, then h2 → h4 inside .prose. Each h2 gets a section symbol prefix; h3 is a normal subhead; h4 becomes a small uppercase label.

This is an h3 subheading

Used for subsections within an h2 block. Slightly larger than body, no decorations.

This is an h4 label

Used for inline labels, captions, or tight metadata sections.

Lists

Unordered list:

  • First item, with the bullet rendered in accent color.
  • Second item, slightly indented from the body text.
  • Third item — items can wrap and the indent is preserved.

Ordered list:

  1. Numbers are rendered in a smaller sans-serif weight.
  2. This keeps them quiet relative to the content.
  3. Useful for step-by-step instructions.

Code

Inline like const x = 42 sits inside running prose. Block code lives in a dark slab with monospace font, designed to read like a terminal: 

function helloWorld() {
  return "documentation that doesn't suck";
}

helloWorld();
// → "documentation that doesn't suck"

Blockquotes

A blockquote is rendered with a left rule in the accent color, italic body, and softer text. Use it for pulled quotes or for citing external sources at length.

Callouts

Tip
The default callout uses the accent color. Wrap content in .callout with a .callout__label child for the heading.
Warning
Use .callout--warn for things the reader should be careful about. The rule and label shift to amber.
Note
Use .callout--note for low-priority asides. Muted gray rule.

Dividers

A horizontal rule renders as a centered fleuron rather than a line:

Use it sparingly to mark major shifts in topic within a single doc.

Images

Drop images into assets/img/ and reference them with relative paths from the page (e.g. ../assets/img/diagram.png). Images max-width to their container by default. Wrap in <figure> with a <figcaption> if you need captions; styling can be added when needed.

Dark mode

The stylesheet includes a prefers-color-scheme: dark block. The site automatically follows the operating system setting — there is no toggle, by design. Switch your OS theme to see it.
