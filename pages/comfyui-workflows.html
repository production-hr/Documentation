ComfyUI: Building Your First Workflow

Node-by-node construction of the classic SDXL checkpoint workflow, the Flux.1 dev split-component workflow, img2img modification, and a reference table of key nodes.

Two workflows follow — the classic SDXL checkpoint workflow (simplest, all-in-one file) and the Flux.1 dev workflow (modern, split components). Build them node by node in order. Right-click on empty canvas → Add Node to find each node by the path listed in the table.

Workflow A — SDXL Checkpoint (txt2img)

The simplest possible workflow. One checkpoint file contains the model, text encoders, and VAE all baked together. Seven nodes total.

Step Node Key Settings What To Do
1 Load Checkpoint ckpt_name: your SDXL .safetensors Add Node → loaders → Load Checkpoint. Select your SDXL checkpoint from the dropdown. This node outputs MODEL (yellow), CLIP (teal), and VAE (pink) — three separate outputs.
2 CLIP Text Encode (Positive) text: your prompt Add Node → conditioning → CLIP Text Encode. Connect CLIP output from Load Checkpoint → clip input. Type your positive prompt in the text field. Outputs CONDITIONING (orange).
3 CLIP Text Encode (Negative) text: blurry, low quality, watermark, deformed Add a second CLIP Text Encode for the negative prompt. Connect the same CLIP output to this node's clip input (one output → two inputs is fine).
4 Empty Latent Image width: 1024 / height: 1024 / batch_size: 1 Add Node → latent → Empty Latent Image. Set 1024×1024 for SDXL. Must be multiples of 64. Outputs LATENT (purple).
5 KSampler steps: 20 / cfg: 7.0 / sampler: dpmpp_2m / scheduler: karras / denoise: 1.0 Add Node → sampling → KSampler. Connect: model (yellow) from Load Checkpoint, positive/negative (orange) from both CLIP Encode nodes, latent (purple) from Empty Latent Image. Outputs a denoised LATENT.
6 VAE Decode — Add Node → latent → VAE Decode. Connect: samples (purple LATENT) from KSampler, vae (pink) from Load Checkpoint. Outputs IMAGE (red).
7 Save Image filename_prefix: ComfyUI Add Node → image → Save Image. Connect images (red) from VAE Decode. Ctrl + Enter to queue and run.
VAE Colour Issue
If your output looks washed out or has wrong colours, your checkpoint's baked VAE has the known SDXL FP16 precision issue. Download sdxl-vae-fp16-fix.safetensors, place it in models/vae/, add a Load VAE node, and connect it to VAE Decode instead of the checkpoint's VAE output.

Workflow B — Flux.1 dev (txt2img)

Flux uses split components: the diffusion model, two text encoders, and a VAE are separate files. This workflow requires all four files downloaded first. See the Reference doc Section 5 for folder placement.

Step Node Key Settings What To Do
1 Load Diffusion Model unet_name: flux1-dev.safetensors / dtype: default Add Node → loaders → Load Diffusion Model. Select flux1-dev.safetensors (or your GGUF). Outputs MODEL (yellow).
2 DualCLIPLoader clip_name1: t5xxl_fp8_e4m3fn.safetensors / clip_name2: clip_l.safetensors / type: flux Add Node → loaders → DualCLIPLoader. Select T5-XXL for clip_name1 and CLIP-L for clip_name2. Set type to flux. Outputs CLIP (teal).
3 Load VAE vae_name: ae.safetensors Add Node → loaders → Load VAE. Select ae.safetensors (Flux.1 VAE). Outputs VAE (pink).
4 CLIPTextEncodeFlux clip_l: short style hint / t5xxl: your full prompt / guidance: 3.5 Add Node → conditioning → CLIPTextEncodeFlux. Connect CLIP from DualCLIPLoader. Write a brief style hint in clip_l and your full descriptive prompt in t5xxl. No negative prompt needed.
5 Empty Latent Image width: 1024 / height: 1024 / batch_size: 1 Same as Workflow A. Multiples of 16 for Flux (not 64). 1024×1024 is the standard starting size.
6 KSampler steps: 20 / cfg: 1.0 / sampler: euler / scheduler: simple / denoise: 1.0 Connect model (yellow), positive conditioning (orange), latent (purple). Set cfg to 1.0 — Flux has guidance distilled in; higher CFG produces artefacts. Use scheduler: simple or sgm_uniform, not karras/dpmpp.
7 VAE Decode — Connect samples from KSampler, vae from Load VAE.
8 Save Image — Connect and queue as before. Ctrl + Enter.
GGUF Flux models
For GGUF Flux models (flux1-dev-Q4_K_M.gguf), use the Unet Loader (GGUF) node instead of Load Diffusion Model. This requires the ComfyUI-GGUF custom node — install via Manager. Everything else in the workflow stays the same.

img2img — Modifying an Existing Image

img2img starts from an existing image instead of empty noise. The key change vs txt2img: replace Empty Latent Image with Load Image + VAE Encode, and set denoise below 1.0 on the KSampler.

Change from txt2img What to do
Add Load Image node Add Node → image → Load Image. Upload or drag your source image onto the node.
Add VAE Encode node Add Node → latent → VAE Encode. Connect: pixels (red IMAGE) from Load Image → pixels input. Connect vae (pink) from Load VAE or Load Checkpoint → vae input. Outputs LATENT (purple).
Replace Empty Latent Disconnect Empty Latent Image from KSampler. Connect VAE Encode's latent output to KSampler's latent input instead.
Set denoise strength On KSampler, set denoise to 0.4–0.7 for typical img2img. Lower = preserves more of the original.
Match resolution The KSampler works at whatever resolution the VAE Encode produced. No need to set width/height separately — it inherits from the input image.

Key Nodes Quick Reference

Node Found Under When to Use It
Load Checkpoint loaders SDXL and any all-in-one checkpoint file. Contains model + CLIP + VAE baked together.
Load Diffusion Model loaders Flux, Qwen-Image, Z-Image, SD3 — any model where diffusion model, encoders, and VAE are separate files.
DualCLIPLoader loaders Flux.1 (needs both CLIP-L and T5-XXL simultaneously). Set type: flux.
CLIPLoader loaders Single-encoder models: Flux.2 (Mistral-3), Z-Image (Qwen3-4B), Qwen-Image (Qwen-VL).
Load VAE loaders Always required for Flux/modern models. Place ae.safetensors in models/vae/.
CLIPTextEncodeFlux conditioning Flux.1 and Flux.1 Kontext only. Has separate clip_l and t5xxl fields plus a guidance parameter.
CLIP Text Encode conditioning SDXL and older models. Single text field. Use two — one positive, one negative.
Empty Latent Image latent txt2img starting point. Sets output resolution.
KSampler sampling Standard sampler for all models. Use SamplerCustomAdvanced for more control (custom noise, sigmas).
FluxGuidance conditioning Flux-specific guidance conditioning node. Use instead of CFG scale. Set guidance: 3.5 for Flux dev.
VAE Decode latent Converts final latent to pixel image. Always the last step before Save Image.
VAE Decode (Tiled) latent Use for very large images (2048px+) to avoid VRAM spikes during decode.
Load LoRA loaders Stack a LoRA on top of the base model. Connect between Load Checkpoint/Diffusion Model and KSampler. Strength 0.5–1.0.
ControlNet Apply conditioning Add structural guidance (depth, edges, pose). Requires a ControlNet model loaded via Load ControlNet Model.
Load Image image Load a source image for img2img, inpainting, or reference workflows.
Save Image image Save output to ComfyUI/output/ folder. Embeds workflow JSON in the PNG metadata.
Preview Image image Shows image in the canvas without saving to disk. Useful for intermediate steps.
