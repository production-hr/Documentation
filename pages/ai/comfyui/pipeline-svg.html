AI Character Pipeline — SVG

The full character pipeline rendered as inline SVG — no JavaScript, no dependencies, scales to any size.

Inline SVG gives you complete control over every element: colours, typography, connector routing, and dark-mode overrides all live in the same document. The tradeoff is verbosity — each box, header, and arrow is an explicit element. The diagram below is a faithful reproduction of the pipeline image, drawn with <rect>, <text>, and <polyline> elements.

Tradeoffs

SVG gives you pixel-perfect control and zero runtime dependencies. Dark mode requires explicit class-based overrides for each colour (see the @media (prefers-color-scheme: dark) block in this page's <head>). The main cost is maintenance: every box position and every arrow waypoint is a hardcoded coordinate. Adding a new node means recalculating downstream coordinates manually.

Tip: Open DevTools and inspect any <rect> or <polyline> to see its exact coordinates. SVG uses a left-to-right, top-to-bottom coordinate system with the origin at the top-left of the viewBox.
