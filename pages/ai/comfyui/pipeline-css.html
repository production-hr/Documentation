AI Character Pipeline — CSS

The full character pipeline built from HTML <div> elements and CSS — no SVG, no scripts, no dependencies beyond the site stylesheet.

Pure CSS flowcharts use flexbox for columns, borders for boxes, and ::after pseudo-elements for arrowheads. The connectors are regular block elements whose width, height, and border colour draw the lines. What you gain is perfect dark-mode integration and full accessibility — the diagram is real DOM, so screen readers can traverse it. What you lose is fine-grained routing control: complex branch angles require careful positioning math.

How it works

The outer .pl container is display: flex; flex-direction: row. Each stage column is a flex child that stacks its groups vertically. The connector elements between stages are fixed-width divs; horizontal arrows use a height: 2px block with an ::after triangle for the arrowhead. The branch and fan connectors use position: absolute children to draw the vertical spine and horizontal arms.

Tradeoffs

CSS diagrams integrate perfectly with the page's typography, spacing, and colour tokens — dark mode works without extra effort. The limitations show up with complex routing: branch connector heights are computed from the rendered layout, so they need to be tuned if content changes. The diagram is real DOM, which aids accessibility but means the HTML is more verbose than the Mermaid source.

Accessibility: Unlike SVG or canvas, these boxes are real <div> elements. Adding role="img" on .pl-wrap with an aria-label summarising the pipeline gives screen readers a meaningful description of the diagram as a whole.
