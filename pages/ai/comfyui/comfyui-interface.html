ComfyUI: Interface Walkthrough

How to navigate the infinite canvas, read node anatomy, decode wire colours by data type, manage the generation queue, and save and load workflows.

ComfyUI's interface is a node graph editor running in your browser. Everything happens on a single infinite canvas — there are no menus, panels, or forms beyond what's on the canvas itself and a small top bar. This simplicity is the point: the graph is the program, and every parameter is visible at once.

Canvas Navigation

Action Input Notes
Pan Middle-click drag or Space + left-click drag Move around the canvas freely. There's no edge — the canvas is infinite in all directions.
Zoom Scroll wheel Zoom in/out centred on your cursor position.
Fit to screen Ctrl + Shift + H Centres and zooms to show all nodes in the current workflow.
Select node Left-click Click on a node to select it. Selected nodes show a highlight border.
Select multiple Ctrl + left-click or drag a selection box Box-select by dragging on empty canvas. Useful for moving groups of nodes.
Move nodes Left-click drag on node title bar Drag by the title bar (top strip of the node). Dragging the body scrolls the node's content.
Delete node Select + Delete key or right-click → Remove Removing a node also removes its connections.
Add node Right-click on empty canvas → Add Node Opens the node browser tree. Or double-click on empty canvas in newer ComfyUI versions.
Group nodes Select multiple → Ctrl + G Creates a Group box. Useful for labelling sections of a complex workflow.

Node Anatomy

Every node has the same structure: a title bar at the top, input slots on the left edge, output slots on the right edge, and parameter widgets in the body.

Part Where What It Does
Title bar Top strip Shows the node name. Click and drag to move the node. Right-click for node options (mute, bypass, clone, pin).
Input slots Left edge — circles/dots Receive connections from other nodes. A slot accepts only the matching data type — mismatched connections are rejected. Unconnected required inputs show in red.
Output slots Right edge — circles/dots Send data to other nodes. One output can connect to multiple inputs simultaneously.
Widgets Node body Dropdowns, sliders, text fields, seed inputs — the direct parameters (steps, CFG, sampler, prompt text, etc.). Widgets can be converted to input slots via right-click → Convert to Input.
Mute toggle Right-click → Mute Greyed-out node is bypassed — its outputs pass through as if it weren't there. Useful for A/B testing (e.g. muting a LoRA).
Bypass Right-click → Bypass Passes inputs directly to outputs without processing. Different from Mute for nodes with pass-through behaviour.

Wire Colours — Data Types

Wires are colour-coded by data type. You cannot connect outputs to inputs of a different type — ComfyUI will refuse the connection. Knowing the colours tells you at a glance what a slot expects.

Colour Data Type What It Carries
Yellow / Gold MODEL The loaded diffusion model (UNet or DiT). Flows from Load Checkpoint or Load Diffusion Model into the KSampler.
Orange CONDITIONING The text embedding output from the CLIP Text Encode node. Positive and negative conditioning are both this type.
Violet / Purple LATENT A latent image tensor — the compressed representation the diffusion model works in. Flows from Empty Latent Image (or VAE Encode) into KSampler, then out to VAE Decode.
Red / Pink IMAGE A decoded pixel image tensor. Output of VAE Decode, input to Save Image / Preview Image, or to VAE Encode for img2img.
Pink (lighter) VAE The loaded VAE model. Flows from Load VAE into KSampler (Flux) or VAE Decode / VAE Encode nodes.
Cyan / Teal CLIP The loaded text encoder. Flows from Load Checkpoint or DualCLIPLoader / CLIPLoader into CLIP Text Encode nodes.
Green INT / FLOAT Integer or float values — steps, seed, width, height, CFG scale, etc.
Light blue STRING Text strings — prompt text before encoding.

The Queue System

ComfyUI runs generations through a queue. Understanding the queue prevents confusion about why nothing is happening or why changes aren't applying.

Concept Explanation
Queue Prompt (Ctrl + Enter) Adds the current workflow to the queue. The current state of all widgets is captured at this moment — changes made after queuing don't affect queued items.
Queue size You can queue multiple generations. They run sequentially. The queue counter in the top bar shows pending items.
Interrupt The Interrupt button (top bar) stops the current generation mid-run. The partial result is discarded.
Clear Queue Removes all pending (not yet started) items from the queue. Does not interrupt the currently running generation.
Auto Queue Toggle in the queue panel — automatically re-queues the workflow after each generation completes. Useful for batch runs. Combine with a random seed to get varied outputs continuously.
Seed behaviour Fixed seed: same seed = same image (deterministic). Randomise: a new random seed every run. Increment: seed +1 each run. Set via the seed widget's mode dropdown on the KSampler.

Saving & Loading Workflows

Action How
Save workflow Ctrl + S or top menu → Save. Saves a .json file. This JSON contains every node, its position, all widget values, and all connections — the complete workflow state.
Load workflow Drag and drop a .json file onto the canvas, or Ctrl + O. Replaces the current canvas entirely.
Load from image Drag and drop a .png image generated by ComfyUI onto the canvas. ComfyUI embeds the full workflow JSON in the image metadata — drag the output image in to restore the exact workflow that generated it.
Default workflow The canvas loads a basic SDXL-style workflow on first run. Save your own starting templates and load them to avoid rebuilding from scratch.
Workflow from web Many workflows are shared as .json files or as images with embedded metadata on OpenArt.ai, the ComfyUI GitHub discussions, and Reddit. Drag them directly onto your canvas.
Tip
Always save workflows as images (Save Image node output) rather than just the .json — the image carries the full workflow inside it, so you have the output and the recipe in one file.
